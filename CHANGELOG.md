[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Planned

## [0.1.2] - 2026-09-20

### Changed

- Updated the project version to 0.1.2.
- Replaced the application icon with a transparent-background version.
- Updated README badges, screenshots, and documentation.
- Improved Debian package release metadata.

### Fixed

- Removed the visible black background around the application icon.
- Updated the application version shown in the UI.

## [0.1.1] - 2026-09-20

### Added

- Live CPU, memory, disk, and uptime monitoring
- System health charts
- Running process monitoring
- Process search
- Mounted filesystem information
- Developer environment detection
- Linux service monitoring
- TCP and UDP port inspection
- Recent system logs viewer
- Log search and log-level filtering
- Automatic data refresh
- Manual page refresh
- Self-contained Debian package
- Custom Linuvera application icon
- JavaFX runtime packaging support
- GitHub Actions CI workflow
- MIT License
- Contribution guidelines
- Pull Request template
- Bug report issue template
- Feature request issue template

### Fixed

- JavaFX runtime packaging issue
- CSS parsing warning in health charts
- Missing application icon resource
- Environment command output formatting

## [0.1.0]

### Added

- Initial Linuvera project structure
- JavaFX desktop application
